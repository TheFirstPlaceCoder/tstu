# MathTool

Консольное приложение на **Java 21** для решения квадратных и линейных уравнений.

Проект разработан в учебных целях и демонстрирует базовые принципы объектно-ориентированного проектирования, разделение ответственности между классами, обработку аргументов командной строки, валидацию входных данных и обработку ошибок.

## Возможности

MathTool поддерживает:

- решение квадратных уравнений вида `Ax² + Bx + C = 0`;
- решение линейных уравнений при `A = 0`;
- определение случая с двумя действительными корнями;
- определение случая с одним действительным корнем;
- определение отсутствия действительных корней;
- интерактивный ввод коэффициентов;
- передачу коэффициентов через аргументы командной строки;
- передачу аргументов в произвольном порядке;
- проверку корректности введённых значений;
- обработку ошибок ввода.

## Требования

Для запуска проекта необходима:

- **Java 21** или новее.

Проверить установленную версию Java можно командой:

```bash
java -version
```

## Сборка проекта

Если проект собирается через Maven:

```bash
mvn clean package
```

После успешной сборки JAR-файл будет находиться в каталоге:

```text
target/
```

Например:

```text
target/mathtool-1.0.0.jar
```

## Запуск

### Справка

```bash
java -jar target/mathtool-1.0.0.jar
```

или:

```bash
java -jar target/mathtool-1.0.0.jar --help
```

### Интерактивный режим

```bash
java -jar target/mathtool-1.0.0.jar solve
```

После запуска программа последовательно запросит коэффициенты:

```text
Введите A:
Введите B:
Введите C:
```

### Передача коэффициентов через CLI

Коэффициенты можно передать сразу при запуске:

```bash
java -jar target/mathtool-1.0.0.jar solve -a 1 -b -3 -c 2
```

Порядок аргументов не имеет значения:

```bash
java -jar target/mathtool-1.0.0.jar solve -c 2 -a 1 -b -3
```

### Запуск из PowerShell

Если путь к `java.exe` содержит пробелы, перед ним необходимо использовать оператор вызова `&`:

```powershell
& "C:\Program Files\Java\jdk-21\bin\java.exe" -jar .\target\mathtool-1.0.0.jar solve -a 1 -b 5 -c 3
```

## Примеры работы

### Два действительных корня

```bash
java -jar target/mathtool-1.0.0.jar solve -a 1 -b -5 -c 6
```

Результат:

```text
Уравнение квадратное
Дискриминант: 1.000
x1 = 3.000
x2 = 2.000
```

### Один действительный корень

```bash
java -jar target/mathtool-1.0.0.jar solve -a 1 -b 2 -c 1
```

Результат:

```text
Уравнение квадратное
Дискриминант: 0.000
x = -1.000
```

### Нет действительных корней

```bash
java -jar target/mathtool-1.0.0.jar solve -a 1 -b 0 -c 1
```

Результат:

```text
Уравнение квадратное
Дискриминант: -4.000
Действительных корней нет
```

### Линейное уравнение

```bash
java -jar target/mathtool-1.0.0.jar solve -a 0 -b 2 -c -4
```

Результат:

```text
Линейное уравнение
x = 2.000
```

## Архитектура

Логика приложения разделена между несколькими классами:

```text
Main
 └── MathToolApplication
      ├── CommandLineParser
      ├── Equation
      ├── EquationSolver
      ├── EquationSolution
      └── SolutionPrinter
```

### Основные классы

| Класс | Назначение |
|---|---|
| `Main` | Точка входа в приложение |
| `MathToolApplication` | Координирует работу приложения |
| `CommandLineParser` | Разбирает команды и параметры командной строки |
| `Equation` | Хранит коэффициенты уравнения и представляет предметную модель |
| `EquationSolver` | Содержит математическую логику решения |
| `EquationSolution` | Представляет результат решения |
| `SolutionPrinter` | Форматирует и выводит результат |
| `MathToolException` | Используется для ошибок приложения |

Такое разделение позволяет отделить:

- ввод данных;
- валидацию;
- математическую логику;
- представление результата;
- вывод пользователю.

## Типы результатов

Результат решения представлен отдельными типами:

```text
LinearSolution
TwoRootsSolution
SingleRootSolution
NoRealRootsSolution
```

Это позволяет не использовать дополнительные флаги для определения того, какой результат был получен.

## Валидация

Программа проверяет:

- является ли значение целым числом;
- переданы ли необходимые параметры;
- находятся ли коэффициенты в допустимом диапазоне;
- корректно ли сформирована CLI-команда.

Пример некорректного значения:

```bash
java -jar target/mathtool-1.0.0.jar solve -a abc -b 2 -c 3
```

Пример сообщения об ошибке:

```text
ОШИБКА: коэффициент A не является целым числом
```

## Используемые технологии

- Java 21;
- Object-Oriented Programming;
- Java Records;

- Pattern Matching for `switch`;

## Принципы проектирования

При разработке проекта использовались следующие подходы:

- **Single Responsibility Principle** — каждый класс отвечает за отдельную часть программы;
- отделение математической логики от пользовательского интерфейса;
- явное представление различных результатов решения;
- централизованная обработка ошибок;
- возможность переиспользования `EquationSolver` независимо от CLI.

## Алгоритмическая сложность

Решение одного уравнения выполняется за постоянное время:

```text
O(1)
```

Дополнительная память также имеет постоянную сложность:

```text
O(1)
```

## Назначение проекта

Основная цель MathTool — продемонстрировать реализацию программы для решения квадратных уравнений с аккуратным разделением логики по классам.

Архитектура проекта позволяет в дальнейшем расширить приложение, например добавить:

- комплексные корни;
- другие типы уравнений;
- графический интерфейс;
- REST API;
- историю вычислений.
